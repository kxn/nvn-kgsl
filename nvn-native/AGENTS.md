# 独立 NVN / Adreno 后端

本目录按用户最新要求直接通过高通硬件原语实现 NVN：Adreno PM4、KGSL、IR3，以及 Android 原生显示和生命周期。原项目的 ARM64 原生装载、离线改写、宿主门和已有系统 HLE 继续复用。

- NVN 的声明、ABI 和行为依据公开 NVN 资料、独立逆向、原 SDK 静态代码和黑盒测试。区分声明与行为证据，记录来源与适用 SDK；不能仅凭一个相似 API 推定语义。
- 不以原 Metal 后端作为行为规范、实现模板或测试 oracle，不继承它的内部对象、录制回放结构、专用分支或性能限制。历史上参考过的行为应独立重新核实，不能只删注释或改名称便宣称已独立。
- 正式接入不能编译、链接或回退到旧 Metal/Vulkan 渲染器。共享 NVN 类型、原游戏模块、装载和系统 HLE 的复用不等于复用旧渲染器，须用实际源码闭包和 ELF 依赖核验。
- NVN 语义与宿主实现分开：硬件命令、资源布局、同步、状态和调度根据 Adreno 原语设计；不模拟 Metal 工作流。允许复用已核实的公共 Maxwell shader 前端及独立 SPIR-V/NIR/IR3 编译工具，不接回 Vulkan 驱动。
- 函数入口覆盖不等于完整语义或真机资格。缺失能力明确报告，不能用空实现、CPU 制造图形结果、改游戏逻辑或未知 ABI 猜测来绕过。

仍遵守仓库的原始输入重建、记录校验、真机证据、独立分支及禁止 CPU 模拟等约束。此文件明确用户对本目录的新后端路线，取代历史文档中将 Metal 实现作为对应标准的描述。
