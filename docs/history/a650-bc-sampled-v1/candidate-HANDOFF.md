## Mechanism and limits

`nn_bc_shadow_plan` calls the existing original runtime FDL C API for formats 0x41 RGB_DXT1, 0x42 RGBA_DXT1, 0x43 DXT3, 0x44 DXT5, UNORM only. It derives each mip's native offsets, pitches and layer strides from FDL, then calls the existing normal `nn_block_copy_plan`. One dispatch per mip can copy all layers. No new GOB/copy/layout/codec algorithm was added. Source Generic16Bx2 allocation, payload extent and public GPU address do not change.

`nn_bc_shadow_create` allocates fresh independent native compressed storage, shared immutable code, one UBO and one normal common-encoder dispatch per mip. Native compressed storage and canonical data are NEVER mapped by the owner. Only code/UBO/command metadata is CPU-written. All caller-owned canonical lifetime/pool-policy admission remains caller responsibility. Fresh private allocation, rather than distinct imported GPUVAs, proves physical disjointness. Every returned owner BO plus canonical appears in `resources()`; a failed cleanup retains reachable BO handles for retry. Pending/unknown submission must retain owner, queue, program and all BOs.

Use `plan.native` (exact zero-GPUVA FDL metadata) for `pipeline_draw_state.sampled_fdl[n]`. `owner.view` after creation is the separate actual-address FDL descriptor; do NOT pass it as zero-address metadata. Corresponding `textures[n].layout` is NULL; `textures[n].buffer` names the actual native storage. Targets continue through the existing RGBA8 validator. Actual descriptor is regenerated by FDL at the true allocation GPUVA; no guessed pitch, alpha swizzle or manual descriptor masks.

First sampled scope is 2D, one selected mip/layer, TXF/TXS or explicit nearest/clamp-to-edge normalized sampler. Arrays/mip-chain conversion has HOST coverage but not sampled admission. Linear filtering, BC sRGB, depth/3D, BC4/5/6/7/ASTC/ETC, NVIDIA compression/metadata, arbitrary sampler state, NVN descriptor registration and game C1 consumption remain unsupported. No extrapolation from BC1..3 to other compressed formats.

Existing normal raw-block CS begins invalidate and completes cache-flush/timestamp-wait/WFI/WFM. The independent qualifier feeds its one-mip dispatch into the existing `nn_tex_shadow_chain`, preserving normal full-cache CS->graphics ordering and original immutable GPUVA tables/sequence BOs. It reuses the command/data-page separation already fixed in that shared module. It does not add CP markers, NOP padding or a new ordering recipe.

## Independent primary format facts

- [Khronos EXT_texture_compression_s3tc](https://registry.khronos.org/OpenGL/extensions/EXT/EXT_texture_compression_s3tc.txt): DXT1 RGB vs RGBA transparency, DXT3/DXT5 opaque color-block rule, explicit/interpolated alpha encoding. This is compressed-codec evidence, not a claim about NVN copy flags or API edge semantics.
- [NVIDIA-authored Khronos DXT1 specification](https://registry.khronos.org/OpenGL/extensions/EXT/EXT_texture_compression_dxt1.txt): little-endian RGB565 endpoint/2-bit selectors; RGB alpha is opaque, RGBA selector3 can be transparent. Our qualification only authors endpoint/transparent cases and never implements a generic decoder.
- Actual FDL metadata source is pinned original Mesa `fd6_layout.c/fd6_view.cc`, reached solely through the already promoted bounded runtime_fdl facade. Earlier ignored BC foundation is evidence/reference only; no stale layout catalogue or old GOB kernel was copied into this new owner.
