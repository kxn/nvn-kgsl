# VS runtime constants and residual native UBOs

This new ignored candidate leaves the SSBO31, joint compiler3 and GPU192 freezes unchanged. Its snapshot baseline and tracked root WIP are recorded in baseline.json. This is independent hardware/compiler work, not game rendering qualification.

The four DWORD VS allocation is padding to a vec4. Actual typed NIR intrinsics determine consumed words; allocation size must not substitute for a mask. The original twelve VS consume BaseInstance through InstanceIndex−BaseInstance. Native direct Draw uses actual signed baseVertex/nonindexed first and actual baseInstance. Adreno's existing indirect packet can set DST_OFF to the actual nonzero driver allocation and updates the first vec4 from GPU argument data on every draw. CPU never reads argument/index BOs. Word3 is inactive in this supported no-streamout profile; word4, clip planes and other driver domains remain rejected. Public DrawID source remains an explicit missing mapping rather than an assumed zero.

The three residual native UBO tables are produced by real constant-range lowering, not the preoptimization resource count. They consume native binding1's original immutable C1. The table descriptor is GPUVA49 plus vec4-sized extent. Full stage reflection independently maps native binding to C1 or NVN API CB; native binding cannot be interpreted as API slot. Use Program's immutable full C1 owner and existing strong pins; direct caller ranges need proven descriptor-rounded bounds. Descriptor holes are zero and no arbitrary BO is fabricated.

Implementation: extend the normal pinned Mesa source overlay with read-only typed facts at the actual allocation/lowering passes; add explicit producer --runtime-constants and new recipe address roles, with exact-recipe/actual-SPIRV sidecar. Default-OFF runtime validates every role, mask, offset and full table before any allocation or command write. Private per-job driver uploads and all dynamic UBO/C1 resources remain live through Finish and unknown quarantine; shader code is not rewritten. Legacy no-runtime recipe bytes and failures stay immutable.

Validation proceeds as one family: authored driver word combinations + direct/indexed/indirect/count draws, nonzero and signed bases, full C1/API dynamic UBO ranges and sparse stage bindings, descriptor extent/alignment/alias/overflow negatives, whole-owner rollback and unknown replay. Recompile all 25 original diagnostic VS against the same fixed diagnostic FS, preserve both old and new errors, and report HOST recipes separately from native GPU and public/game availability. No arbitrary all-pairs shader catalogue or guessed specialization is introduced.
